# 演示视频与最终交付检查

## 视频分成两种用途

1. 收藏品动作参考：可以按角色动画文档使用图生视频，再制作成可运行游戏动画。
2. 比赛演示视频：需要在游戏完成后录制真实操作，再剪辑。没有公司现成视频完全不影响制作，不用现在寻找视频库存。

## 60—75秒演示剪辑脚本

| 时间 | 真实画面 | 说明文字或旁白 |
| --- | --- | --- |
| 0—6秒 | 营地主界面，展示已有收藏 | 读懂英语，规划路线，带回新的收藏。 |
| 6—20秒 | 打开一局，听音、标记目标、连接路线 | 英语帮助孩子找到目标，路线选择带来游戏乐趣。 |
| 20—32秒 | 展示一次错误提示和修正 | 在提示中完成任务，基础奖励不要求满分。 |
| 32—44秒 | 完成、开箱、查看收藏互动 | 每次探索留下成果。 |
| 44—56秒 | 展示系列进度、心愿、星砂兑换 | 随机带来惊喜，积累让每个孩子都能获得心仪收藏。 |
| 56—68秒 | 换另一个词包，保持同一玩法 | 同一套规则，可以承载不同学习内容。 |
| 68—75秒 | 实际游戏入口与结尾 | 词境探险队。画面中仅加入已验证可访问的链接或二维码。 |

## 交给剪辑工具的完整提示词

```text
请用我上传的《词境探险队》真实屏幕录制，剪辑一段60—75秒的参赛演示。按照附上的时间脚本组织。保留真实操作顺序，不伪造游戏没有的功能、学习效果、用户数量或反馈。未提供的镜头列为待补录，不使用AI重画界面冒充实际运行画面。
视觉沿用奶油白、探险绿、天空蓝和深蓝。标题、字幕后期排版，中文清晰，字号适合观看。转场简单，不做快速闪切。英语发音片段优先保留原音，旁白时降低背景音乐。若演示某件随机收藏，请使用明确标记的演示模式或真实抽取结果，不暗示必得概率。
输出宽高比16:9、1920×1080像素、目标30fps的MP4主版，手机操作画面保持比例，侧边可排简短说明。可另剪9:16、1080×1920像素的竖版；所有原录屏等比适配，不横向拉伸。另导出中文字幕SRT和剪辑时间表。没有真实录屏前只输出分镜，不宣称已经制作成品视频。
```

## 实际来源记录模板

每件实际成品记录：assetId、文件名、实际使用工具/模型（如可知）、生成日期、提示词ID、参考图来源、生成或下载来源、适用授权链接/文件、后处理步骤、审核状态。未知信息留空并注明未知，不能让AI补造。

## 交付检查清单

- 每件图片独立文件，主图与派生图分开，命名与台账对应。
- 透明背景是真的alpha；小尺寸识别清楚，肢体不裁切。
- 角色统一，章鱼腕数、翼龙与鲸鱼等结构检查通过。
- 动画有真实预览；无法分层的文件不声称已经是可编辑分层稿。
- 英语文字经审阅、语音经试听；未经审核内容保持草稿状态。
- 音乐循环接缝经检查，音效音量不会盖住英语声音。
- 棋盘模板按明确规则验证有解，资源引用和ID均存在。
- 概念封面、动作参考与真实游戏演示清楚区分。
- 生成提示词不等于素材成品，计划路径不等于实际文件。
