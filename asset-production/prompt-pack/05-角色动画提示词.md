# 角色动画提示词

## 推荐制作方式

普通收藏用平移/缩放/旋转配合少量独立粒子即可；珍藏采用经分层整理的素材或连续帧。主图没有分层时，不把整体变形冒充真实摆尾。可以先用图生视频验证动作，但输出的视频不自动等于可接入游戏的透明精灵动画。

## A01 主角五个动作：交给代码/动画工具

```text
以附上的explorer.png为唯一角色身份参考，为《词境探险队》制作待机、移动、思考、开心、鼓励五个状态，保持帽子、背包、面部、比例、配色和轮廓完全一致。相机固定，无镜头移动，不增加道具或背景。
如果只有单张位图，先实现整图轻微平移、缩放和旋转的可运行基础版，明确标为整体变换；不要声称已经实现骨骼步行动画。若制作真正的手脚或面部动作，需要提供分层部件或逐帧素材，并检查肢体连接与身份一致。
单帧比例1:1，源帧1024×1024，游戏导出512×512；所有帧使用同一锚点与缩放，四边至少10%安全边距。交付可播放预览、动作参数、资源依赖和减少动画版本。主体始终位于相同落脚位置，不因不同动作跳变尺寸。
```

- `idle`（待机）：轻呼吸、眨一次眼，3秒。
- `move`（移动）：轻微交替步伐、身体小幅起伏，1.2秒循环，原地动作不改变画面位置。
- `think`（思考）：略微歪头，眼睛看向上方，再回到中立，2秒。
- `happy`（开心）：小幅抬手、轻跳一次后回到原位，2秒。
- `encourage`（鼓励）：微笑并轻轻挥手，不哭泣、不失望，2秒。

以下提示词用于代码或动画助手：

```text
使用附上的18件收藏图片和上表动作规格，生成每个收藏品的动画配置与可播放HTML预览。普通品优先使用轻浮动、摆动、缩放及独立粒子；无法从整张位图单独摆动肢体时，先提供整体轻动效并记录需要分层的项目。
珍藏品：小霸王龙需要独立尾部、头部或对应帧；机器人需要眼部、胸灯和手臂；鲸鱼需要尾部、眼部和可单独绘制的气泡。分层依赖未提供时明确列出，不虚构源文件。动作起止回到同一姿态，提供减少动画模式。
所有素材沿用同一风格、相机、1:1画幅和缩放；动画单帧源图1024×1024，运行帧512×512，逐帧动画目标12—24fps。不要加入文字、声轨、自动抽奖、弹窗或改变奖励逻辑。交付独立动作ID、时长、循环属性和参数文件。
```

## V01—V03 珍藏品图生视频动作参考

仅在图生视频工具中使用，必须上传对应已确认的主图。优先得到动作参考，再制作游戏实际动画。普通MP4通常没有透明通道；输出格式和透明能力取决于工具。需要去背景或逐帧清理时应单独处理，不能仅靠提示词保证无缝循环。

### V01 小霸王龙

```text
使用上传的little-tyrannosaurus.png作为唯一主体身份参考。创作4秒固定镜头的游戏收藏品动作短片，宽高比1:1，目标1024×1024像素（工具仅支持1080时用1080×1080），目标24fps，方形画幅，主体位置和尺寸始终稳定。完全保留上传图的画风、颜色、比例、五官和所有结构，不增加或删除肢体，不生成文字或声轨。
动作：探头、眨眼、甩尾。动作轻柔，先短暂停留，再完成一次小动作，最后回到起始中立姿态；首尾尽量一致。四周保留原有安全边距，无镜头推拉、旋转、切换或动态模糊。
如果支持透明输出则使用真实alpha；否则使用均匀纯色背景，并说明后续需抠像。不得生成假棋盘格透明背景。避免主体变形、闪烁、身份漂移和遮挡轮廓的大量特效。
```
