# 《词境探险队》统一素材提示词包

日期：2026-09-16。当前交付是提示词、示范文本和生成脚本清单，**不是已生成图片、视频或音频**。此次不调用收费API，无需提供密钥。

## 先设置比例

生成前先看[比例尺寸与导出规格](09-比例尺寸与导出规格.md)：角色/收藏1:1，手机背景9:16，横封面16:9。每个独立图片提示词和JSON也已加入明确规格，工具设置需要同步选择。

## 从哪里开始

1. 打开[图片提示词](02-图片提示词.md)，先复制 **P00** 到你使用的绘图工具，生成统一风格参考。
2. 选定一张，保存为`style-anchor.png`。之后每次生成都附上这张参考图；不同工具切换时仍附同一张图。
3. 先做 **P01探险员、C06小霸王龙、C12机器人、C18小鲸鱼、B01营地**。检查是否像同一款游戏，再做其余15件收藏品。
4. 界面图标和简单动画使用[代码生成提示词](04-界面与程序动效提示词.md)，复杂角色动作用[动画提示词](05-角色动画提示词.md)。
5. 音乐、音效与配音分别使用[音频提示词](06-音乐音效与配音提示词.md)，不让语音工具朗读“导演说明”。
6. 无需公司词库：包内提供48个词的示范内容和任务草稿，见[内容说明](07-词库与教学内容提示词.md)。正式投用前审阅文本与试听，不能声称已经匹配公司教材。
7. 宣传视频脚本见[演示视频提示词](08-演示视频与交付检查.md)。比赛操作画面必须来自做好的真实游戏，当前无需公司提供视频。

缩略图、未解锁轮廓从已完成主图派生；路线、按钮、简单图标和徽章用SVG/CSS；开箱粒子用程序；系列封面由现有素材排版；中英文标题由界面排版，避免图片中的错字。字体使用具有适当许可的现有字体，AI不能替你生成字体许可。

## 交付边界

统一风格提示词可以减少漂移，但需要参考图与人工筛选。普通图生视频不一定输出透明背景或无缝循环，单张位图也不会自动变成真正分层稿。所有此类要求均需后处理或代码制作。生成结果和参考素材的来源、工具、时间与授权情况应留档。

# 统一风格规范

## 风格总提示

```text
为原创英语学习网页游戏《词境探险队》制作正式美术素材，受众为约9—12岁儿童。统一采用“圆润探险玩具”风格：有柔和体积感的2D游戏插画，哑光软胶玩具质感，简洁的大色块和清楚的轮廓，少量细节；有趣、精致，避免婴幼儿风格与写实照片。统一柔和光源来自左上方，阴影短而柔和；不使用摄影景深。主要配色为探险绿#268574、天空蓝#6FB5DF、暖奶油白#FFF8EC和深蓝#24364B。整体低至中饱和，局部可用暖橙或浅黄色点缀。保持在手机小尺寸下可辨认。禁止现成IP、商标、水印、任何文字、数字、字母、边框以及未经要求的配角。
```

## 单体资源构图

```text
独立单体游戏资源，1:1方形画布，目标规格1024×1024。正面偏四分之三视角，相机高度接近主体中部，保持参考图的视角；展示完整轮廓，主体最大外接尺寸约占画布75%，四周至少留10%安全空间。主体居中，无地台、无额外道具、无场景。真正的透明背景并保留alpha；不把棋盘格画进图片。如当前工具不支持透明输出，使用纯色#FF00FF背景，不让该颜色进入主体，后续单独抠图。不能裁掉尾巴、鳍、角、翅膀或天线。
```

## 参考图用法

```text
如果附有参考图：将style-anchor.png仅作为风格参考，沿用其材质、轮廓处理、视角和光线，不复制其中的机器人外形；如果另附本主体已确认的图片，则将该图作为身份参考，保持比例、五官、配色和特征。参考图中的背景与文字均不移入结果。
```

## 三个系列

| 系列 | 配色与形态 |
| --- | --- |
| 恐龙探索 | 苔绿、暖橙、奶油白；柔和自然形状，角和骨板仍然清楚 |
| 太空旅行 | 天空蓝、蓝紫、浅黄；圆润硬表面，灯光克制 |
| 海洋奇遇 | 青蓝、珊瑚橙、奶油白；柔和流线形，身体结构准确 |

## 统一避免项

不要照片写实、金属镜面、过多毛发、强景深、密集背景、细碎纹理、恐怖牙齿、侵权角色、文字水印、拼图、被裁掉的肢体或假透明棋盘格。不要混用像素风、扁平线稿和写实3D。

## 样张检查

先按128px缩小看是否认得出；在奶油白和深蓝底上分别检查透明边缘；比较视角、光源、轮廓和比例。错了只改一个明确问题，再对照参考图复查。保留未裁切主图和实际生成记录。

## 比例速查

单体角色/收藏/图标：1:1；手机背景：9:16；横封面/系列封面：16:9；展示台：2:1；收藏卡底板：3:4；角色动作单帧：1:1。完整像素、格式、安全边距及适配规则见[比例尺寸与导出规格](09-比例尺寸与导出规格.md)。

特别核对：read在本词包读现在时/riːd/；close为动词/kloʊz/；T. rex按tee reks读；三角龙、剑龙、翼龙等名称需逐条试听。收藏名称中的兴趣词不自动加入常规学习测试。

## 音频交付检查

音频和CSV一一对应；去除无意义的长静音但保留完整起音与尾音；无削波、无异常响度跳变；人工试听英文发音、句子自然度和空缺提示。保留原始音频，运行时MP3与WAV源文件分开。不能只检查“文件存在”就标记听审通过。

## 2. 主体大小与安全边距

### 单个角色与收藏品

- 主体外接框最长边约占画布的75%，允许70%—80%；不是身体宽和高都强行占75%。
- 四边至少留10%空白；1024画布即至少约102像素，安全区包含尾巴、角、翅膀与天线。
- 静态主体居中，所有同一角色动作保持画幅、缩放与锚点一致。
- 站立角色落脚锚点约为画布中心横坐标50%、纵坐标85%；有底座等特殊形态单独记录，不强行改变画面比例。
- 游动或悬浮物体以中心为锚点。动画动作全过程不能出画；需要更大动作空间时整组同比缩小。
- 缩略图使用contain等比适配，禁止cover裁掉收藏品。

### 竖屏背景

- 上方约20%保留低细节区域，用于标题和状态栏。
- 中央区域低细节，棋盘背景尤其不要画实际棋盘、文字、按钮或可交互物件。
- 营地关键装饰优先落在横向12%—88%、纵向22%—82%范围；边缘只放可被裁掉的环境装饰。
- 底部约15%降低细节，用于操作按钮。安全区是构图建议，不应画出参考线。
- 手机屏幕未必是9:16。背景可等比cover并检查9:19.5、9:20屏幕的左右裁切；棋盘和按钮仍由布局独立安排。
- 桌面优先使用居中的移动端游戏区域或专门宽屏布局，不把竖图横向拉满。

### 封面与系列卡面

- 16:9封面四边至少留8%安全边距，上方约25%可留标题区。文字后期添加。
- 系列卡面主物件距离边缘至少8%，图片合成时等比缩放，角色不重新绘制。

## 3. 生成工具不支持推荐尺寸时

1. 优先选择明确的宽高比：单体1:1、背景9:16、横封面16:9。
2. 分辨率可采用工具支持的同等比例尺寸，之后等比导出。透明度需要检查实际alpha，不能只看PNG扩展名。
3. 工具若只支持2:3，先生成较宽松的竖构图，再向上下扩图为9:16；不能把1024×1536直接变形拉成1152×2048。
4. 工具若只支持3:2封面，优先左右扩图到16:9，或检查安全区后裁掉少量上下内容。
5. 提示词不会自动设置工具参数。界面有比例、尺寸、透明度选项时，必须同时设置。
6. 使用四分之三视角描述的是相机角度，不是3:4图片比例。

## 4. 动画和视频规格

- 角色主图、动作参考、精灵单帧统一为1:1，不把整张横向精灵图当作单帧比例。
- 图生视频动作参考：4秒、目标24fps、相机固定。工具实际帧率可能不同，后处理时统一。
- 游戏连续帧动画：可用12—24fps，按实际观感与资源体积选择；帧序列需有帧宽、帧高、总帧数、锚点与播放速度说明。
- 图集宽高由行列数决定，不能把图集整体等比拉进一个角色格。
- 比赛主视频：16:9、1920×1080、30fps目标；屏幕录制保持真实比例。原素材帧率不足时不要宣称具有额外真实运动细节。
- MP4动作参考一般不含透明度；游戏透明动画需独立处理，不把纯色背景当透明。

## 5. 音频规格（与宽高比无关）

| 类型 | 推荐源文件 | 运行时建议 |
| --- | --- | --- |
| 单词、任务、收藏语音 | 单声道WAV，工具支持时48kHz/16bit | 单声道MP3，约96—128kbps |
| 短UI音效 | WAV，48kHz/16bit，按素材需要单声道或立体声 | WAV或压缩格式，实际浏览器试听 |
| 循环音乐 | 立体声WAV，48kHz/16bit | 立体声压缩音频；检查循环接缝 |

采样率是推荐交付规格，不要求上采样假装提升音质。保留原始音频，避免削波和明显响度跳变；具体响度以实际游戏混音试听为准。
