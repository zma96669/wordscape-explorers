# 界面、图标与程序动效提示词

本文件中的代码块交给能够生成代码的AI。SVG是实际矢量资源，CSS/JavaScript是可播放效果；普通绘图工具无法保证输出可编辑SVG。可以附style-anchor.png作视觉参考，但不能让AI将整张位图嵌入SVG假装矢量。

## U01 统一图标与基础控件

```text
为英语学习网页游戏《词境探险队》制作一套可直接使用的原创SVG图标和CSS控件，并附纯HTML资源预览页。
风格：圆润探险玩具的清爽界面，适合9—12岁；颜色#268574、#6FB5DF、#FFF8EC、#24364B。图标采用圆角、简洁几何，避免精细纹理。图标画幅比例1:1，SVG使用统一viewBox 0 0 64 64，PNG备用导出256×256像素，描边约3，round端点。使用可编辑path/shape，不嵌入base64位图，不依赖外网字体、CDN或外部脚本。
每个图标单独文件：back.svg、play.svg、undo.svg、reset.svg、audio.svg、audio-muted.svg、hint.svg、settings.svg、collection.svg、exchange.svg、wish.svg、stardust.svg、duplicate.svg、bridge.svg、boots.svg、compass.svg、correct.svg、needs-revision.svg、task-complete.svg、series-complete.svg。
为控件提供默认、hover、focus-visible、pressed、disabled状态：主按钮、次按钮、返回按钮、图标按钮、弹窗、标签、进度条、任务卡、提示气泡、提示层、音量切换。移动端触控目标至少44 CSS像素。状态同时以形状/文字呈现，不仅依赖颜色。正文至少保持清晰对比，检查而不是声称未经测量的对比度合格。
交付：SVG文件、components.css、preview.html和简短README，预览页在浅色与深色底显示24/48/64像素图标及各控件状态。展示真实资源，不用占位emoji替代。游戏标题《词境探险队》由HTML可访问文本排版，不从生成图片中识别文字。字体先用系统回退；若包含下载字体，必须同时交付其实际许可文件和来源。
```

## U02 棋盘、收藏箱和展示设施

```text
为《词境探险队》生成可编辑SVG资源和一个静态浏览页。统一参考风格：探险绿#268574、天空蓝#6FB5DF、奶油白#FFF8EC、深蓝#24364B，圆角几何、轻微立体感、柔和左上光源。使用清楚的大形状，适合手机4×4棋盘；不得把文字画进棋盘素材。
逐个文件输出：ground.svg、path.svg、start.svg、exit.svg、ravine.svg、exploration-point.svg、route-segment.svg、target-marker.svg、route-valid.svg、route-invalid.svg、display-stand.svg、main-stand.svg、collection-card.svg、chest-closed.svg、chest-open.svg、chest-empty.svg。
棋盘组件比例1:1，统一viewBox 0 0 128 128，PNG备用导出256×256像素，正面轻俯视，边缘可相邻拼接。沟壑在格内表达，保持与道路对比。路线与目标标记采用透明底覆盖层，不遮挡英文词卡。营地出口为小帐篷符号，起点为脚印符号。
收藏箱三种状态均为1:1，viewBox 0 0 256 256；展示台及主展示台均为2:1，viewBox 0 0 256 128；收藏卡底板为3:4，viewBox 0 0 240 320。收藏箱使用同一结构与配色，箱体和箱盖有稳定ID，关闭/开启/空箱是同一箱子的状态，不是三种外形。箱体不写字，不用钥匙孔暗示付费解锁。展示台和卡底保持简洁，主要注意力留给收藏品。
所有形状为真正SVG节点，不嵌入位图。逐一检查viewBox、裁切、透明底、大小缩放和浏览器显示。附资源预览页和检查说明。
```

## U04 通用游戏与奖励动效

```text
为《词境探险队》制作独立HTML/CSS/JavaScript动画预览，复用实际图标、箱体和收藏素材；不调用付费服务，不依赖后端。
实现并分别可触发：按钮轻按80—120ms、标记出现160ms、路线绘制180ms、每格移动220—320ms、词卡飞入任务栏300ms、正确确认220ms、需修正时温和提示350ms、桥梁出现300ms、指南针指路500ms、完成结算600ms、开箱约1.2s、普通收藏出现约0.7s、珍藏出现约1.4s、重复转化约0.7s、兑换成功约0.7s、系列完成约1.5s。
以transform和opacity为主，不频繁改变布局；粒子数量克制。珍藏强调主体动作和柔和光点，不采用老虎机转盘、急促闪烁或长时间悬念。收藏品动画不包含永久性属性加成。
提供“跳过”和“减少动画”，响应prefers-reduced-motion。可重复触发、不堆积计时器。声音仅预留事件回调，不假装音频已经存在。动画本身不授予奖励，奖励由业务状态决定，重复播放不重复发奖。
交付命名清晰的动画接口、样式和预览页，注明真实资源依赖、持续时间与循环属性。将效果参数与业务逻辑分开。
```

```text

不覆盖原始主图。交付可重复运行的转换脚本、转换清单、浅色/深色底联系表。不存在的源图标记missing，失败文件标记failed，不输出虚假的成功记录。
```
