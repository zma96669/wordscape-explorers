# 词库与教学内容提示词

## 已准备的示范内容

本包提供48词，分为“日常名词24词”和“动作及描述24词”。另有96个听音/含义任务及24个语境任务，共120个任务草稿。它们是可编辑的演示内容，不是公司正式词库，也没有声称对应某册教材或已经教研审核。

任务配置先使用列明的正确项和干扰项。大部分基础任务故意采用差异较大的干扰项，以降低首版负担；后续可以增加同词性、相近词义的干扰，但必须重新检查歧义。不能把其他任意词直接混入棋盘后仍假定每题唯一正确。

所有词、提示、任务都带审核状态。没有审阅通过之前不要删除这些标识。名词图像只在有教学必要时制作，不需给48词都生成图片。动词和形容词不能机械地用单件静物表达。

### 文件

- `content/vocabulary.json`：48词、中文目标词义、词性、英语释义与音频文件名。
- `content/tasks.json`：120个任务及正确项、候选干扰、解释与提示。
- `content/voice-script.csv`：48条单词、72条任务、36条收藏语音，共156条待录制文本。听音任务复用单词音频。

## 用AI扩展词包的完整提示词

```text
你是一名面向中国小学三至六年级的英语学习内容编辑，为《词境探险队》生成示范词包。任务是巩固已学词汇，不要自称匹配任何指定教材或经过教研审核。
输入为附上的vocabulary.json与tasks.json。先沿用其字段和ID约定，检查重复ID，再补充一个24词词包。提供目标词义、词性、自然简短的英语释义、中文解释、单独音频路径和draft_pending_education_review状态。
每词提供听音与含义任务；适合语境填空的词另外提供语境任务。每任务有明确correctIds和3个distractorIds，所有ID须存在。语境使用___表示空缺，口播版本在空缺处说blank，不读出正确答案。
含义、语境或反义关系需要限定语义。不要因中文解释宽泛把合理答案判错。明确列出可接受的替代答案；若当前词包不能提供无歧义干扰项，标为待修改而不是强造。名词单复数、动词时态、形容词比较级要与句子一致。
反馈描述具体知识点，不能说“聪明/笨”，不能把单次答对声称为永久掌握。提示逐级给出，不要第一条提示就只说答案。不要引用不存在的教材、研究或审查结论。
输出两个合法UTF-8 JSON文件，并另给需要人工确认的问题清单。不输出音频文件已完成的虚假记录。
```

## 教研审阅提示词

```text
请审核附上的vocabulary.json和tasks.json。这是机器辅助制作的教学草稿，请独立逐题检查：目标词义、词性、自然表达、年龄适配、大小写和单复数、题目与解释一致、所有候选项是否存在第二种合理答案、读音是否有多音歧义、提示是否能帮助理解。
输出结构化问题表：taskId、问题、证据、可接受的其他答案、修正文本、严重程度。对于仅通过程序检查的问题和需要英语教研判断的问题分别注明。不要宣称代替真人听审，不要因为格式正确就标记教学已审核。
```

## 游戏文案生成提示词

```text
为《词境探险队》生成完整zh-CN界面文案JSON，使用稳定的英文键名。游戏流程是：查看任务、标记词卡、连线、出发、在提示下修正、结算、开收藏箱、收藏柜、星砂兑换、营地展示。
对象为小学三至六年级。句子短、具体、友好，避免幼儿化和过度夸奖。提供首次引导、全部按钮、路线不合法、步数不足、未完成目标、音频失败、中途退出、进度保存失败、收藏空状态、获得新收藏、重复转化、兑换、系列完成、音频设置和减少动画选项。
奖励文案使用当前设计：普通档90%、珍藏10%；普通档优先未拥有；基础星砂1，表现最多加1；普通兑换6，珍藏12；普通重复转2，珍藏重复转4。数值放占位参数中，避免写死在多处。声明这些是初版配置，可调整。
不使用“错过就永远没有”“最后机会”“不回来伙伴会伤心”等催促表达。不要求满分才能领基础收藏。反馈用“这次独立找对了……”等具体描述，不给人格评价。
输出合法JSON和占位参数说明，状态为draft_pending_review。
```

## 关卡配置生成提示词

```text
根据附上的游戏设计文档和词库，准备1个3×3教学棋盘和8—12个4×4棋盘模板。上下左右移动，不能重复经过格子，起点终点不同，路线上需经过标记目标；普通步数预算按地图配置。
先识别尚需实现方明确的规则，例如障碍占格、桥梁跨越计步、错误目标修正后的路线重画。明确采用的假设，不把未定规则伪装成已确定。
每模板提供稳定ID、坐标、起终点、障碍、目标候选位置、步数上限、难度和一条完整可行路线。附验证脚本，逐步检查邻接、不重复、不碰未获准跨越的障碍、目标覆盖和步数。实际运行脚本后才能标为validated；未运行只标draft。不要用“已测试通过”描述推测。
任务答案只能从审核过的候选集配置；如果随机替换导致歧义或无解，需要重新生成，不可发布给孩子。
```
