# 自动调用图片模型

项目已经接入 Codex 自带的 ImageGen CLI，并把 OpenAI Python SDK 安装在项目目录 `.codex/imagegen-python`。默认中转站地址为：

```text
https://nai.xuelilaoshi.cn/v1
```

## 第一次配置

在项目根目录打开 PowerShell，运行：

```powershell
.\asset-production\scripts\configure_imagegen.ps1
```

根据提示在终端里输入中转站 API Key。输入内容不会显示，Key 只保存到 Windows 当前用户环境变量，不会写入项目文件，也不要把 Key 发到聊天里。

## 测试图片接口

配置完成后运行：

```powershell
.\asset-production\scripts\test_imagegen.ps1
```

测试默认使用 `gpt-image-2`、`1024x1024`、低质量，只生成一张低成本连通性测试图：

```text
output/imagegen/connection-test.png
```

这一步会验证中转站是否真正兼容 `POST /v1/images/generations`，因为模型列表中出现图片模型，并不等于图片接口和返回格式一定兼容。

## 批量生成

准备好 JSONL 任务文件后运行：

```powershell
.\asset-production\scripts\run_imagegen_batch.ps1 `
  -InputFile .\tmp\imagegen\prompts.jsonl `
  -OutputDir .\output\imagegen\batch `
  -Concurrency 3
```

每行是一个独立任务，可以指定不同提示词、模型、尺寸、质量和输出文件名：

```json
{"prompt":"A friendly compass badge, centered, no text, no watermark","model":"gpt-image-2","size":"1024x1024","quality":"low","out":"compass.png"}
{"prompt":"A warm illustrated treasure map, no text, no watermark","model":"gpt-image-2","size":"1536x1024","quality":"medium","out":"treasure-map.png"}
```

默认先用 `gpt-image-2` 验证。`gpt-image-2-2k`、`gpt-image-2-4k` 或 `gpt-image-2.5-*` 是否支持相同参数，应分别用一张测试图确认后再批量运行。当前 CLI 面向 `gpt-image-*` 图片模型；`grok-imagine-image` 和视频模型需要另一套兼容接口，不能直接混入这份批处理。

角色关键帧需要先确认中转站同时支持 `POST /v1/images/edits`。确认后以 `assets/art/characters/explorer.png` 为角色参考图，先生成 `move` 的 8 帧并检查角色一致性，再继续其他动作，避免一次生成大量不可用素材。
