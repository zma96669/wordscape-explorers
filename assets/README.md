# 运行资源目录

本目录只保存游戏和评审展示实际需要的交付资源，避免把同一内容以 PNG/WebP、WAV/MP3 两套格式重复发布。

- `art/`：角色、背景、收藏品、缩略图和轮廓，运行格式为 WebP。
- `motion/`：透明逐帧动画，运行格式为 512×512 WebP。
- `audio/`：英语语音与背景音乐使用 MP3；短操作音效保留 WAV。
- `ui/`：SVG、CSS 和少量透明 WebP 界面资源。
- `showcase/`：项目提交需要的展示截图，保留 PNG。

PNG 美术母版、动画 PNG 序列和音乐 WAV 母带属于制作过程文件，不进入发布包。它们可通过 `asset-production/` 中的提示词和生成脚本重新制作，历史版本也保存在 Git 提交记录中。
